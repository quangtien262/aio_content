Thiết lập CI cho dự án Node.js với GitHub Actions

Pipeline CI tốt phải tái lập môi trường sạch và nhanh chóng trả lời rằng thay đổi có vượt qua lint, kiểu dữ liệu, kiểm thử và build hay không.

Các bước tối thiểu

Workflow cần checkout mã, setup-node với phiên bản cố định, cache kho tải npm, chạy npm ci rồi lint, typecheck, test và build. npm ci cài đúng lockfile và thất bại nếu manifest lệch.

Mở rộng hợp lý

Dùng matrix khi hỗ trợ nhiều phiên bản Node, tách job khi cần chạy song song, upload báo cáo khi lỗi, đặt timeout và hủy lượt cũ của cùng pull request.

Bảo mật workflow

Giới hạn quyền token, khóa phiên bản action đáng tin cậy và không đưa bí mật cho mã pull request không tin cậy. Chỉ deploy sau khi toàn bộ kiểm tra bắt buộc đã qua.
